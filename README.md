# Suzanne Awards

Add extra gratification to your Blender usage with achievements!

<hr>

## Work In Progress

This project is actively under development and still does not feature all functionality, graphics, or sounds that it will on its first release. DO not expect a full experience until the release of version 1.0.

## AI Disclosure

Claude Sonnet was used to help construct various parts of the system, including the UI, toast, and many of the source integrations that allow the addon to track actions for achievements. This code has been tested and is is in the process of being refactored and rewritten with more efficient methods and greater documentation.
